# Piko — White/Purple 3D Glassmorphism Design Assets

Brand direction: **Piko — Your Tiny Desk Buddy**. This refreshed direction replaces the earlier dark/lime style with warm white surfaces, pastel lavender, violet accents, expressive glossy 3D mascot artwork, frosted-glass panels, soft shadows, and subtle ambient glow.

## Files
- `Piko.ico`: multi-size Windows icon.
- `Piko_App_Icon.png`: 512×512 app icon preview.
- `Piko_White_Purple_AppIcon_1024.png`: 1024×1024 high-resolution app icon.
- `icons/`: PNG icon sizes for app/browser use.
- `Piko_Glassmorphism_Concept_01.png` through `03.png`: visual concept boards for notch states, dashboard, notifications, storage, tasks and controls. These are reference mockups, not functioning UI.
- `ANTIGRAVITY_IMPLEMENTATION_PROMPT.txt`: updated prompt to paste into Antigravity.

## Suggested palette
- Warm white: `#FBFAFF`
- Lavender-white: `#F1EDFF`
- Light purple: `#DCD0FF`
- Lavender: `#BBA2FF`
- Violet: `#8B5CF6`
- Deep violet: `#5B3AA8`
- Main text: `#242044`
- Muted text: `#756F93`

The UI references are concept artwork. Antigravity should implement the layouts, animations and behavior in the actual WPF code and keep text contrast and accessibility in mind.
